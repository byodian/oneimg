# Offer Style Presets before User Template authoring

The initial product will offer Style Presets for Template Family, Theme, Density, Page Format, constrained brand values, Logo, and compatible identity choices, while withholding a Template Builder, arbitrary CSS, free positioning, and User Template marketplace. The schema reserves a future declarative User Template origin and permission model, accepting less open-ended customization now in exchange for immediate polished results, local export certification, and an interface suitable for people without design expertise.
