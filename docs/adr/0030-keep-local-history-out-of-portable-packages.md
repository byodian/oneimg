# Keep local history out of portable Packages

OneIMG Packages will contain committed current Documents, required Assets, presentation declarations, integrity data, and optional Project organization and Package Previews, while excluding Edit Transactions, checkpoints, Trash, caches, Jobs, receipts, accounts, authorizations, and interface state. This sacrifices cross-device undo in exchange for smaller packages, less deleted-content exposure, and keeping local implementation details out of the long-lived compatibility format.
