# Open in an editable Draft and edit the rendered Document

OneIMG will restore the latest Meaningful Draft or an unlisted Untouched Draft directly, with typing, paste, and image drop available before Project naming, template choice, or onboarding. The rendered Document becomes the primary editor and Clean Preview only hides overlays around the same Canonical Render Root, accepting a substantial editor-shell migration in exchange for removing the first-use gate and making the polished result immediate for non-designers.
