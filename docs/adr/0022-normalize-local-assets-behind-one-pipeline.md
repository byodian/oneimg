# Normalize local Assets behind one Pipeline

OneIMG will preserve immutable Asset Originals locally while one content-addressed Asset Pipeline supplies normalized Render Sources and disposable Asset Derivatives to editing and export. This accepts derivative storage, ingestion work, and a dedicated recovery lifecycle in exchange for avoiding Base64 document state, bounding decoded memory, supporting local format Adapters, and keeping orientation, color, crop, and image identity consistent under the WYSIWYG Contract.
