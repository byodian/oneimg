# Send minimal ephemeral Export Snapshots for High-Fidelity Export

High-Fidelity Export will send only the immutable Export Snapshot, normalized Render Sources, and semantic Asset metadata referenced by the selected output, never Asset Originals, a complete Project, history, unrelated Document, derivatives, cache, or secret. The Export Service explicitly deletes inputs after rendering and deletes private output after the client receives its complete Blob, on cancellation, or after a maximum 15-minute interrupted-download retry window; a per-Job alarm is authoritative and a one-day object lifecycle is only defense in depth. This accepts a dedicated, testable privacy lifecycle in exchange for certified browser rendering without broadening the data exposed by Remote Export Authorization.
