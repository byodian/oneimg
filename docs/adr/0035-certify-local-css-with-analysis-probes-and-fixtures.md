# Certify Local CSS with analysis, probes, and fixtures

Local Export eligibility will combine Template capability declarations, build-time analysis of actual Style Packs and layout recipes, revision-keyed runtime micro-probes, and preview-versus-artifact fixtures. CSS is classified as Local Certified, High-Fidelity Required, or unsupported rather than inferred from ordinary browser support; OneIMG accepts delayed admission of newer effects and browser-specific routing in exchange for never labeling a visibly different export successful.
