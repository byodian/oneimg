# Build Faithful PDF from canonical Page artifacts

The initial PDF output will assemble each PDF Page from the corresponding canonical Page raster artifact and Export Plan dimensions rather than invoke another layout engine. This accepts raster-based text and no ATS, semantic-accessibility, CMYK, bleed, or professional-print claims in exchange for a practical resume, notice, and guide format that preserves the same visible composition as Canonical Preview; any future semantic PDF will be a separately certified Adapter.
