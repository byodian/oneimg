# Keep AI explicit, proposal-based, and nonessential

AI Assist will never be required for Smart Paste, editing, Local Export, Packages, or initial Scenes; a user must explicitly request a named transformation, authorize any remote transfer, review a Conversion Draft, and accept changes as one reversible Edit Transaction. Sensitive Documents cannot use remote AI initially, and AI cannot invent missing resume, notice, or travel facts. This accepts fewer automatic transformations in exchange for authorship, privacy, truthfulness, offline operation, and predictable history.
