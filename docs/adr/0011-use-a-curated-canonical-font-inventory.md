# Use a curated canonical font inventory

The initial product will use a small versioned inventory of redistribution-approved Canonical Fonts that are available in both local preview and High-Fidelity Export, referenced by stable identifiers rather than embedded repeatedly in OneIMG Packages. Arbitrary font upload is deferred until licensing, package size, offline caching, and remote-render authorization can be handled explicitly. This trades typographic freedom for deterministic layout, faster export, legal clarity, and fewer choices for non-designers.
