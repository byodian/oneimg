# Use intent-driven media composition instead of freeform layout

Media Groups will preserve semantic item order, Featured state, Focal Point, zoom, fit, and one constrained Media Arrangement while the active Template computes tested geometry for the current Page Format. OneIMG accepts fewer manual layout controls and rejects arbitrary coordinates, layers, free rotation, and free collage in exchange for non-designer-friendly results, reusable content, deterministic adaptation, and the WYSIWYG Contract.
