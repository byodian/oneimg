# Group Page Format variants into Template Families

OneIMG will present one Template Family for a structural design idea and implement its supported ratios and pagination rules as tested Format Adapters rather than duplicate catalog entries. Content changes may produce a Presentation Suggestion, but never silently replace a user-selected Family, Theme, Density, or Page Format; only declared responsive behavior inside the current Family may adapt automatically. This trades some implementation complexity for a smaller catalog, coherent design intent, and stable user choice.
