# Persist the local core through one IndexedDB Repository

The initial local core will persist versioned Documents, Blob-backed Assets, transactions, checkpoints, Trash, settings, migration state, and disposable caches through one deep Local Repository Module implemented with responsibility-specific IndexedDB stores. OneIMG accepts schema and migration ownership in exchange for transactional local autosave, broad browser reach, removal of Base64 content state and broad clearing, and the ability to defer an OPFS byte Adapter until measurements justify a real second implementation.
