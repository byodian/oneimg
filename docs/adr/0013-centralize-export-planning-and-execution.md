# Centralize export planning and execution

OneIMG will place capability assessment, immutable snapshotting, Local versus High-Fidelity routing, rendering, encoding, slicing, packaging, caching, progress, cancellation, and failure policy behind one deep Export Engine Module. Its Interface plans a request, runs the resulting Export Plan, and cancels an Export Job; Local, owned remote, and in-memory test Rasterizer Adapters sit behind an internal seam. Opening export options performs planning only, while an explicit run rasterizes each normal-size Page once and reuses that Page result for compatible encodings, copy, slices, bundles, and Faithful PDF. This prevents rendering policy from spreading through dialogs and Scene code, removes eager duplicate work, and makes the same observable contract the production and test surface.
