# Make accessibility, privacy, and security release contracts

OneIMG will treat WCAG 2.2 AA critical workflows, content-free telemetry and crash reporting, purpose-specific permission timing, inert package and rendering data, external-resource ownership, and a documented threat model as release gates rather than post-launch improvements. This accepts additional cross-device, assistive-technology, sanitizer, fuzz, and isolation testing in exchange for a creation tool that remains usable and trustworthy with personal resumes, internal notices, and local media.
