# [Spec] OneIMG 公开教程与 AdSense 投放准备

## Problem Statement

OneIMG 已有产品首页、浏览器本地编辑能力以及 AdSense 基础脚本，但广告脚本当前随全局布局加载，公开内容页与编辑区之间缺少明确的执行边界。About 和 Blog 仍有占位内容，隐私政策、同意管理入口和可控广告位尚不完整。

访问者需要真实、有用的使用教程与明确的数据处理说明；创作者需要在广告投放后继续安心使用本地编辑和导出；维护者需要一个可验证、默认关闭广告、账户配置完成后可启用的版本。代码就绪、Google 审核、后台配置和生产启用必须分别记录，不能相互替代。

## Solution

建设简体中文的精简公开内容区，完成 About、隐私政策、使用条款、四篇真实教程、站内导航和搜索发现能力。保留现有域名与默认编辑入口，仅对完整、有效的教程详情页开放正文结束后的一个手动广告位，采用 Google CMP 处理适用地区的同意与隐私选择。

编辑区与可执行广告脚本的页面之间建立完整页面上下文边界；编辑器、Studio、测试场景、错误及其他非白名单页面不加载广告脚本。继续使用现有本地存储位置，不引入数据迁移或改变 Document Core、Canonical Renderer、Local Export 的权责。

本轮交付代码、教程与配图、验证证据以及去敏的上线配置清单。实际账户后台操作、生产部署和真实广告验收属于后续工作；默认不开启真实广告。

## User Stories

1. 作为首次访问者，我希望首页能引导我找到教程，以便了解工具后开始创作。
2. 作为中文读者，我希望教程列表和正文清晰易读，以便在手机和桌面完成学习。
3. 作为初学者，我希望通过快速开始教程完成输入、预览和导出，以便得到第一张图片。
4. 作为长图创作者，我希望了解完整长图与多张切图的实际操作，以便选择合适结果。
5. 作为创作者，我希望理解现有模板、主题色和尺寸的作用，以便调整作品呈现。
6. 作为返回用户，我希望了解现有 .oneimg 文件的保存与恢复方式，以便备份本地内容。
7. 作为读者，我希望步骤和截图对应实际可用的编辑器，以便不被尚未发布的能力误导。
8. 作为读者，我希望看到真实的维护与更新信息，以便判断教程是否适用。
9. 作为读者，我希望无效文章地址返回真正的 404，以便理解内容是否存在。
10. 作为访问者，我希望查看项目背景和既有公开联系渠道，以便了解维护方并反馈问题。
11. 作为访问者，我希望随时找到隐私政策和使用条款，以便了解服务边界。
12. 作为创作者，我希望政策准确说明本地内容保存与第三方广告数据处理，以便理解两者的区别。
13. 作为适用地区的访问者，我希望通过 Google CMP 作出隐私选择，以便广告处理符合我的选择及适用要求。
14. 作为访问者，我希望重新打开隐私设置并修改或撤回选择，以便持续控制偏好。
15. 作为编辑器用户，我希望编辑页不执行广告脚本，以便创作过程不混入广告服务。
16. 作为从教程进入编辑器的用户，我希望此前执行的广告脚本不继续驻留在编辑页面上下文中，以便页面边界真实有效。
17. 作为返回用户，我希望已有浏览器本地内容仍可读取、编辑和导出，以便这次改动不影响我的作品。
18. 作为教程读者，我希望广告与正文、创作入口和下载操作清楚区分，以便避免误触。
19. 作为手机读者，我希望广告加载不会遮挡内容或明显挤动页面，以便稳定阅读。
20. 作为网络受限的读者，我希望广告失败、无填充或被拦截时仍能阅读和进入编辑器，以便学习不中断。
21. 作为创作者，我希望广告不进入作品预览和任何现有导出结果，以便作品保持完整。
22. 作为搜索访问者，我希望有效教程具有独立标题、描述和规范地址，并可从 sitemap 发现，以便访问正确页面。
23. 作为维护者，我希望广告默认关闭且配置无效时不请求广告，以便未就绪的部署保持安全状态。
24. 作为维护者，我希望区分本地验证与账户、域名相关的待验事项，以便不把模拟结果误报为真实上线成功。
25. 作为维护者，我希望通过现有浏览器测试入口验证页面与网络行为，以便持续防止广告越界回归。
26. 作为维护者，我希望工单、日志和验证材料不含私密信息，以便公开协作不会泄露账户或用户数据。

## Implementation Decisions

1. 保留现有域名、公开 URL 与默认 /editor 创作入口；/studio 仍受现有开关控制，不在本轮发布为默认体验。
2. 以独立页面上下文隔离公开广告页面与编辑区。可使用多个根布局或等效的整页导航方案，但仅卸载脚本组件不算满足要求；需通过行为证明边界。
3. 同域方案不构成 IndexedDB 或 localStorage 的权限隔离。公开说明不能承诺广告页面在浏览器权限上无法访问同源存储，也不声称广告服务实际读取了草稿。
4. 不更改既有编辑器本地存储的源、名称、格式或内容，不重构 Document Core、Local Repository、Canonical Renderer 或导出模型。新 Studio 的版本化 OneIMG Package 不等同于旧编辑器当前的 .oneimg 文件；教程描述实际旧流程。
5. 公开内容包括首页、About、隐私政策、使用条款、教程列表和教程详情；沿用现有反馈渠道，无需新增邮件发送、表单后端或用户账号。
6. 首批四篇教程分别覆盖快速开始、长图与切图导出、模板与尺寸、.oneimg 文件保存与恢复。正文、截图和可复核步骤基于实际可用功能，避免云备份、离线保证、智能排版或新 Studio 能力的未验证承诺。
7. 正文、图片与交付文档存放在项目 docs 目录。采用仓库内可维护的内容文件和最小文章索引；不引入 CMS、标签、分类、搜索或可执行用户内容。
8. 文章标识必须对应真实记录；未知标识返回 HTTP 404，不生成占位正文。文章显示真实维护及更新信息，所有作者字段遵循 Git 配置和既有约定。
9. 只允许有效教程详情页成为广告候选；首页、列表、About、政策、赞助、编辑器、Studio、测试场景和错误页均不加载 AdSense 广告脚本。
10. 广告使用显式启用开关、发布商配置和广告位配置。默认关闭；缺失或无效配置不初始化广告、不产生无效账户请求。测试使用明显虚构的合成值，不读取真实账户配置。
11. 采用 Google CMP，并在实施时核对当前官方接入方式。按地区、同意状态和适用要求处理请求；不得自行用普通 Cookie 提示或单个布尔值替代认证 CMP，也不假设非个性化广告无需 Cookie 同意。
12. 公开页面提供隐私设置入口；编辑器通过整页导航访问公开隐私页面，不为该入口在编辑区引入广告或 CMP 执行代码。CMP 不可用时提供真实、可理解的状态与政策入口，不伪装为设置已生效。
13. 区分 CMP 所需资源和 AdSense 广告资源。非广告公开页面仅在隐私设置确有需要时使用官方允许的 CMP 资源，不因此开放广告投放；官方配置存在冲突时保持广告关闭并报告约束。
14. 首期每篇教程仅一个正文结束后的手动广告位；无 Auto ads、锚定、悬浮或插屏形式。广告与创作、保存、下载操作清楚区分。
15. 广告槽预留适合断点的空间，并处理初始化、重新挂载、加载失败、被拦截和无填充；失败不阻塞内容与导航，不自动循环请求或刷新广告。
16. 广告区域处于作品渲染与导出区域之外；适用于现有编辑器及仍可访问的其他编辑页面，不扩张为新增 PDF 或新导出能力。
17. 公开导航和页脚连接所有必要页面；有效页面具备独立标题、描述和 canonical。sitemap 仅包含有效、可公开索引的内容，不包含编辑、测试及无效页面。
18. 核对现有 ads.txt 授权记录与受保护配置的一致性及正式域名可达性，但不把真实发布商标识复制到工单。ads.txt 的检查与站点审核分别记录。
19. 全球访问采用适用地区的 CMP 消息与选择机制。首期正文为简体中文；不承诺全球所有隐私法义务可由同一弹窗自动满足。
20. 不收集作品正文、图片、文件名、剪贴板、本地记录或截图来监测广告；继续遵守内容无关遥测及敏感内容边界。
21. 实施文档给出配置项用途、后台操作类别、关闭方式和验收步骤，只用占位说明。真实账户标识、联系信息、凭据、配置值和含敏感内容的截图不进入 spec、tickets、评论或报告；公开页面所需联系信息由实施阶段从已授权公开来源核对。
22. 本地通过、账户已配置、审核通过、生产部署完成和真实广告验证通过必须分别表述。缺少外部条件时标记待验证，不为了达成验收而绕过 CMP 或开启真实广告。

## Testing Decisions

- 主验收入口为现有 Playwright 驱动的真实公开网页与浏览器网络观测。通过用户能看到的页面、地址、HTTP 响应、下载结果和请求行为验证，不锁定私有函数、布局文件组织或组件内部状态。
- 参考现有浏览器创建与恢复、文件导出和资源拦截场景的做法。新增公开页面测试不依赖 Studio Scenario Harness，不为了广告改造 Document 模型。
- 对第三方资源统一在浏览器上下文边界拦截，提供合成响应和可观察执行标记；测试不访问真实广告、不使用真实账户配置、不点击广告。
- 在“广告开启且使用合成有效配置”的测试中先证明教程上的脚本确实执行，再进入编辑器，证明新上下文不保留该执行标记且没有广告请求。只测试默认关闭不足以证明隔离。
- 覆盖直接进入编辑器、教程到编辑器、编辑器到教程、重新加载、浏览器返回和前进。考虑正常整页加载和浏览器页面恢复行为，不要求与用户无关的特定路由文件结构。
- 使用合成的旧编辑器内容验证已有本地数据可恢复、编辑和导出；不读取真实用户草稿、不输出真实本地数据。
- 覆盖广告关闭、配置缺失或错误、有效教程、非白名单页面、未知文章和 404。编辑区在所有配置状态下均不得加载广告脚本。
- 覆盖 CMP 的适用地区、待选择、接受、拒绝、已保存选择、重新打开、修改或撤回，以及资源不可用状态。适用要求依当前官方规范实现；合成测试仅证明站点编排，不能证明实际后台消息已发布。
- 对首篇教程做完整浏览器路径验证；其余三篇检查实际步骤、真实示例配图及有效入口。基础页面文字修改不逐句编写实现镜像测试。
- 在桌面与手机视口验证阅读、导航、政策和隐私设置的键盘可达性、广告位置及异常状态；验证预览与导出区域无广告污染。
- 通过可观察响应检查无效文章 404、独立 metadata、canonical 和 sitemap 内容。检查清单不包含私密数据。
- 每张功能 ticket 自带与其行为相称的验证，不将所有测试延迟到最后。最后的发布演练仅汇总跨功能证据与外部待验事项。
- 完成与改动相称的类型、lint 和必要工程检查；遵循平台限制，WSL 中不得执行任何包含 build 的命令或间接执行相关命令。规划文档阶段无需运行应用构建和测试。
- 记录并清理任务启动的浏览器、服务器和辅助进程，保留既有用户进程；验证退出后再报告完成。

## Out of Scope

- 实际生产部署、DNS 改动、AdSense 后台操作、账户申请与审核结果承诺。
- 真实广告展示、真实 CMP 后台发布、真实地域行为的生产验收；本轮仅提供后续执行步骤。
- 独立内容子域名和浏览器存储权限隔离；同源权限限制需要准确披露。
- Studio 默认切换、旧 UI 收缩、文档模型迁移、云同步或协作。
- 英文内容站、完整多语言体系、模板中心、场景中心、分类标签、站内搜索和 CMS。
- 登录、会员、支付、广告收益后台、主动邮件发送或新增反馈后端。
- 自动广告、悬浮广告、插屏、激励广告、广告刷新或反广告拦截流程。
- 为本任务新增 PDF、托管导出、AI 或其他创作能力。
- 将文章数量、SEO 配置或 ads.txt 当作审核通过保证。

## Further Notes

- 规格与任务依据本次规划中的已确认选择综合而成。GitHub 工单仅承载去敏的行为要求；敏感配置由授权环境管理，截图只用专门准备的示例内容。
- 产品需遵循既有领域术语、信任与安全规格、本地数据边界及将可访问性、隐私和安全作为发布契约的 ADR。本规格是公开内容变现准备的独立工作，不阻塞或改写其他 Studio 交付事项。
- 发布 triage 使用仓库现有 ready-for-agent 标签。标签代表规格足够明确，实际执行仍需遵守每张任务的 Blocked by 关系。
