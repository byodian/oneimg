Cloudflare 对 `process.env` 的兼容开关和默认日期规则见[Workers process.env 文档](https://developers.cloudflare.com/changelog/post/2025-03-11-process-env-support/)。OpenNext 区分本地、构建期和运行时变量；正式部署需在授权的 Cloudflare Worker 环境配置运行时值，见[OpenNext 环境变量说明](https://opennext.js.org/cloudflare/howtos/env-vars)。本地 CLI 预览验证不等于 Cloudflare Dashboard 已设置。
