## What to build

当显式启用、必要配置有效且满足适用隐私条件时，真实教程详情页可初始化正文结束后的一个手动广告位，其他页面保持无广告请求。

## Acceptance criteria

- [x] 集中处理启用开关、发布商与广告位配置，默认关闭；配置缺失或错误不请求广告，不把实际配置值写入文档、工单或日志。
- [x] 仅有效教程详情页可加载广告脚本；首页、列表、About、政策、赞助、编辑区、Studio、场景和错误页不加载广告脚本。
- [x] 每篇正文结束后最多一个手动广告位，不使用 Auto ads、悬浮、锚定、插屏、自动刷新或循环重试。
- [x] 依据 Google CMP 的正式信号与适用要求处理广告请求，不通过推测同意或临时布尔标志绕过 CMP。
- [x] 广告与正文、开始创作和下载操作清楚区分；在手机和桌面有相称的空间预留，不遮挡内容。
- [x] 初始化、重新挂载、加载失败、无填充或广告拦截不导致重复初始化、正文阻塞或导航失效。
- [x] 用上下文级第三方响应替身证明教程上脚本先成功执行，再进入编辑器时执行标记不驻留且没有广告请求；覆盖返回、前进和重新加载。
- [x] 广告区域不会进入现有作品预览或导出；不为本 ticket 扩展创作或导出能力。
- [x] 测试只使用合成配置和拦截响应，不请求或点击真实广告，并验证非白名单和无效文章的拒绝路径。
