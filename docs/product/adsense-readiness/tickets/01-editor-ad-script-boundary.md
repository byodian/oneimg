# [AdSense Slice 01/08] 建立公开页与编辑区的广告执行边界

本地状态：实现与本票据的本地验收完成。账户、审核及生产环境事项按[交付状态](../delivery-status.md)记录。

## Parent

[Spec] OneIMG 公开教程与 AdSense 投放准备（发布时关联实际 spec issue）

## What to build

用户可在现有公开页与编辑器之间往返，编辑页始终处于无广告脚本的独立页面上下文，已有本地内容不受影响。

## Acceptance criteria

- [x] 移除全站无条件加载广告的行为；默认配置下所有页面均不请求真实广告。
- [x] 在保留现有 URL 和存储位置的前提下，形成可承载公开内容的页面布局，并让公开区与编辑区跨越完整页面上下文边界。
- [x] 直接进入编辑器、公开页进入编辑器、返回、前进及重新加载时，编辑器不执行或请求广告脚本；Studio、测试场景和错误页同样不加载。
- [x] 用合成脚本执行标记验证旧公开页上下文不会继续驻留在编辑页；后续真实广告编排场景由广告 ticket 补充。
- [x] 使用合成既有本地内容完成恢复、修改和现有格式导出的回归验证，不迁移或清空用户存储。
- [x] 保留现有元数据、字体、样式、提示及默认创作入口；不改变 Studio 发布开关。
- [x] 仅声明页面执行隔离，不宣称同源浏览器存储权限隔离。
