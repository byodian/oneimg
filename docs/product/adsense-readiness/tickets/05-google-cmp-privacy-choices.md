# [AdSense Slice 05/08] 接入可重新打开的 Google CMP 隐私选择

本地状态：实现与本票据的本地验收完成。账户、审核及生产环境事项按[交付状态](../delivery-status.md)记录。

## What to build

适用地区的访问者可通过 Google CMP 作出并重新修改隐私选择；不可用状态有真实解释，编辑页保持无第三方广告执行代码。

## Acceptance criteria

- [x] 实施前核对当前 Google 官方集成契约，采用认证 Google CMP，不用自制 Cookie 弹窗或布尔同意值替代。
- [x] 提供可发现、可键盘操作的隐私设置入口，并支持按官方机制重新打开、修改或撤回相关选择。
- [x] 入口关联真实隐私政策；编辑器通过完整页面导航访问公开隐私页面，不在编辑区引入广告或 CMP 执行代码。
- [x] 区分 CMP 资源与广告资源；非广告公开页的隐私设置需求不扩大广告白名单。
- [x] 对适用地区的待选择、接受、拒绝、已有选择、修改或撤回、资源不可用场景进行合成验证，提供广告 ticket 可使用的正式编排契约。
- [x] 拒绝或不可用状态下正文与编辑入口仍可访问；不假设非个性化广告自然免除 Cookie 同意义务。
- [x] 官方配置与既定脚本边界冲突时保持广告关闭并报告原因，不静默绕过用户选择。
- [x] 提供去敏的后台消息配置与后续真实域名验收步骤；模拟结果不标记为账户已配置或生产 CMP 已发布。
