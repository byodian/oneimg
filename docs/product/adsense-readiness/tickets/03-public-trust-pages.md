# [AdSense Slice 03/08] 让用户找到真实的项目信息与数据政策

本地状态：实现与本票据的本地验收完成。账户、审核及生产环境事项按[交付状态](../delivery-status.md)记录。

## Parent

[Spec] OneIMG 公开教程与 AdSense 投放准备（发布时关联实际 spec issue）

## What to build

访问者可从公开页面进入 About、隐私政策与使用条款，理解本地创作和广告数据处理的区别，并使用既有反馈渠道。

## Acceptance criteria

- [x] 完成 About、隐私政策和使用条款的真实简体中文内容，不保留占位文案。
- [x] 关于维护方与联系方式的页面信息仅来自已授权公开来源，不将实际身份、邮箱或账户信息复制到工单和验证记录。
- [x] 隐私政策准确说明现有本地保存与清理风险，以及 Google 等广告服务的数据处理、Cookie 与隐私选择入口。
- [x] 准确披露同源页面隔离边界，不声称浏览器存储已加密或第三方脚本没有同源存储权限。
- [x] 条款只描述当前服务能力、用户内容和素材责任，不编造公司主体或尚未提供的云服务承诺。
- [x] 公开导航和页脚提供政策、About 及联系入口；采用既有反馈渠道，不新增发送邮件或反馈后端。
- [x] 政策与 About 页面不加载 AdSense 广告脚本；所有页面在手机及桌面可读，链接和键盘路径有效。
- [x] 用实际页面行为验证入口、关键说明和广告请求边界，不逐句复制文案写测试。
